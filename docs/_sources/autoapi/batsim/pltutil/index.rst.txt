.. py:function:: make_figure_axes(ny=1, nx=1, square=True)

   Create a Matplotlib figure with one of BATSim's preset subplot layouts.

   :param ny: Number of subplot rows.
   :type ny: int, optional
   :param nx: Number of subplot columns.
   :type nx: int, optional
   :param square: Select the taller preset size for the supported ``2 x 1`` layout.
   :type square: bool, optional

   :returns: ``(fig, axes)`` where ``fig`` is a Matplotlib figure and ``axes`` is a
             flat list of axes in creation order.
   :rtype: tuple

   :raises TypeError: Raised if ``ny`` or ``nx`` is not an integer.
   :raises ValueError: Raised if the requested layout is not one of the supported presets.


.. py:function:: determine_cuts(data)

   Determine display cuts for image data using fixed percentiles.

   :param data: Image array used to calculate display cuts.
   :type data: ndarray

   :returns: ``(min_cut, max_cut)`` from the 5th and 98th percentiles of the
             flattened input data.
   :rtype: tuple of float

   :returns: Image artist returned by ``matplotlib.pyplot.imshow``.

.. py:function:: stitch_images(images, direction='horizontal', spacing=None)

   Stitch equal-sized Galsim image objects into a single composite image.

   :param images: Images to stitch together. All images are expected to share the same
                  dimensions and pixel scale.
   :type images: sequence of galsim.Image
   :param direction: Direction in which images are concatenated. ``"square"`` arranges the
                     images on a square grid, leaving any unused cells blank.
   :type direction: {"horizontal", "vertical", "square"}, optional
   :param spacing: Placeholder for future gap support. Only ``None`` is currently
                   implemented.
   :type spacing: None, optional

   :returns: Composite image when ``spacing`` is ``None`` and ``direction`` is
             supported; otherwise ``None``.
   :rtype: galsim.ImageF or None


.. py:function:: split_image(image, nsplit, direction='horizontal', spacing=None)

   Split a stitched GalSim image into equal-sized image stamps.

   :param image: Input image to split.
   :type image: galsim.Image
   :param nsplit: Number of equal pieces to extract along the split direction.
   :type nsplit: int
   :param direction: Axis along which the input image is split.
   :type direction: {"horizontal", "vertical"}, optional
   :param spacing: Placeholder for future gap support. Only ``None`` is currently
                   implemented.
   :type spacing: None, optional

   :returns: List of split images when ``spacing`` is ``None`` and ``direction`` is
             supported; otherwise ``None``.
   :rtype: list of galsim.ImageF or None
