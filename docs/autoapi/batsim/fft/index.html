_rfft_centered_image(xp, image, real_dtype, complex_dtype, center_index=None)[source]

Compute rfft2(ifftshift(image)) without explicitly shifting the image.

The input image remains in the centred real-space convention. The phase correction converts the spectrum to the convention that would have been obtained by first applying np.fft.ifftshift(image).

_apply_centering_phase(xp, spectrum, n, center_index=None)[source]

Apply the Fourier phase equivalent to np.fft.ifftshift before an FFT.

This avoids materialising a shifted real-space image, which is expensive for very large supersampled stamps.

_apply_pixel_response(xp, spectrum, n, fine_scale, pix_scale)[source]

Apply the square-pixel Fourier response in-place on an rfft2 grid.

The response is separable, so this avoids allocating a full 2D pixel FFT.

_block_integration_response(xp, k, fine_scale, mode='quadrature', integration_order=None)[source]

Return the 1D Fourier response introduced by block integration.

_compensate_block_integration(xp, spectrum, n, fine_scale, min_response=0.001, mode='quadrature', integration_order=None)[source]

Remove the fine-pixel averaging response introduced by block integration.

Gauss-Legendre block integration approximates the mean surface brightness over each fine-grid pixel, introducing a separable pre-smoothing response. Divide out this response within the represented Fourier band before applying the physical PSF convolution.

mode="quadrature" removes the discrete Gauss-Legendre transfer function for the configured nodes and weights. mode="exact_sinc" keeps the ideal top-hat response compensation available as an explicit option.

_extract_centered_coarse_image(xp, image, downsample_ratio, center_index=None)[source]

Return fftshift(image)[::downsample_ratio, ::downsample_ratio] without explicitly materialising fftshift(image).

This keeps the expensive full-resolution image shift out of both GPU and CPU memory paths. Only the already-downsampled coarse image is gathered.

_extract_centered_real_space_coarse_image(xp, image, downsample_ratio)[source]

Extract the aligned coarse grid from a centred real-space fine image.

Unlike _extract_centered_coarse_image, this is for images that have not passed through an inverse FFT and therefore are already in spatial order.

_convolve_psf_fft(xp, gal_prof, scale, pix_scale, psf_obj, downsample_ratio, draw_method, dtypes, psf_mode, integration_order=1, integration_compensation_mode='quadrature', center_index=None, target_flux=None, profile=False)[source]

Convolve the sampled galaxy with PSF and/or pixel response using rFFT.

The expensive path avoids explicit fftshift/ifftshift operations. Instead: - centred real-space images are converted by Fourier phase correction; - the pixel response is applied separably in-place; - the full fine-grid image is inverse FFT’d, then downsampled in real space.

psf_mode="kvalue" samples GalSim’s analytic Fourier PSF through the C++ backend, avoiding a real-space PSF draw and an extra FFT.
