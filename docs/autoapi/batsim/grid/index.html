class FineGrid[source]

Description of the high-resolution grid used by the renderer.

The fine grid is where BATSim samples the GalSim profile before any Fourier-space PSF or pixel convolution to ensure any fine-structure and non-affine shear is adequately sampled. fine_compact records the GalSim-recommended compact support at fine_scale so callers can inspect whether a size cap forced the simulation grid smaller than that support.

The returned factor is the requested total anti-aliasing budget before it is split between sub-pixel integration and FFT supersampling.

_resolve_simulation_ngrid(gal_obj, psf_obj, scale)[source]

Choose the coarse-grid simulation size.

This is deliberately independent of the requested final output ngrid and is only run when no user specified grid size is provided.

_make_fine_grid(gal_obj, scale, sim_ngrid, supersample, pad, max_fine_grid=None)[source]

Construct the fine grid used for sampling and convolution.

The grid is at least large enough for the padded coarse simulation region and is rounded up to a whole number of supersampling blocks so later downsampling is exact.

_resolve_integration_sampling(supersample, integration_order)[source]

Split the anti-aliasing budget between integration and FFT supersampling.

The product of the returned FFT supersampling and integration order covers the requested total supersampling, with the integration order capped so it never exceeds that total budget.

_integration_offsets(xp, fine_scale, integration_order, dtype)[source]

Return sub-pixel offsets and weights for Gauss-Legendre block integration.

The weights integrate over one fine pixel in normalized coordinates and therefore sum to one.
