_prepare_transforms(transform_obj, xp, dtype=None)[source]

Move transform objects to the selected backend once per sampling call.

Transforms that do not provide to_backend are left untouched, which preserves support for simple user-defined transform objects.

_apply_prepared_transforms(coords, transform_obj, xp)[source]

Apply backend-prepared transforms to a coordinate array.

Transforms are applied in the order supplied by the caller.

_sample_galaxy_profile(gal_obj, coords, fine_scale, real_dtype)[source]

Sample the galaxy surface brightness using the compiled C++ backend.

The Python renderer keeps coordinates on the selected array backend until this boundary, then passes NumPy coordinates to GalSim’s C++ API to sample flux at each coordinate.

_sample_galaxy_profile_on_stamp(gal_obj, stamp, transform_obj, fine_scale, real_dtype, xp, integration_order=2, profile=False)[source]

Sample the locally integrated galaxy profile on the fine simulation grid.

For integration_order > 1, each fine pixel is evaluated at Gauss-Legendre sub-pixel offsets and reduced to one integrated fine-grid value before returning to the FFT pipeline.

_sample_psf_spectrum(psf_obj, n, fine_scale, complex_dtype)[source]

Sample the analytic PSF Fourier transform on an rFFT frequency grid.

This backs psf_mode="kvalue" and returns a spectrum in the same layout as numpy.fft.rfft2/cupy.fft.rfft2.
